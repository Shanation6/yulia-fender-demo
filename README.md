## Взаимодействия и доступность

Переключатель тем меняет пояснение, активная кнопка использует aria-pressed, пояснение aria-live. FAQ — native details/summary. Реальные якоря, VK-ссылки и телефон. Контент видим без JavaScript; noscript поясняет остальные темы. CSS учитывает reduced motion; видимый keyboard focus и skip link. Нет аналитики, трекеров или сторонних запросов со страницы.
